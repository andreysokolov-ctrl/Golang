# Учусь программировать на Go

Учебный репозиторий с упражнениями, заметками и небольшими проектами. Здесь я изучаю Go и закрепляю новые знания на практике.

## Что изучаю

- основы языка: переменные, типы данных, условия и циклы;
- функции, срезы, карты и структуры;
- методы, интерфейсы и обработку ошибок;
- пакеты, модули и тестирование;
- основы конкурентности.

## Требования

- установленный [Go](https://go.dev/dl/);
- редактор кода с поддержкой Go.

Проверить установку можно командой:

```sh
go version
```

## Запуск и тесты

Из каталога проекта выполните:

```sh
go run .
```

Запустить тесты текущего модуля:

```sh
go test ./...
```

## Структура репозитория

По мере обучения в репозитории будут появляться отдельные каталоги с упражнениями и небольшими программами. Инструкции по запуску конкретной работы будут находиться в соответствующем каталоге.

> Код и заметки предназначены для обучения и могут меняться по мере освоения Go.
